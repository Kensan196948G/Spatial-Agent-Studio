# 本番リリース準備計画（Spatial Agent Studio）

最終更新：2026-11-20
対象：**本番環境 `https://spatial-agent-studio.mirai-dx-platform.com`**（プレビュー `spatial-agent-studio-preview` とは別系統）
判断：本番公開・AIエージェント実装・運用整備を、番号付きの作業単位（WBS）として列挙する。
実行者欄：**AI** = 当セッションで実施可能／**人** = 人間の操作（承認・ダッシュボード・サービス操作）／**AI+人** = AIが準備し人が最終操作。

## 8. 実行順（推奨）

1. **A1→A2→A3→A4**（本番Pages・ドメイン）… AIが実行
2. **A5**（Access暫定: 既知の管理者アドレスで保護）→ **B1/A6**（P1のメール取得後に4名へ拡張）
3. **C1〜C10**（AIエージェント抽象化・安全境界・テスト）… AIが実装
4. **A7〜A10・D1〜D5**（本番API/DB/運用）… 一部は人
5. **D2/D3**（バックアップ・監視）
6. **E1〜E5**（非機能の定義と検証）
7. **G1〜G4**（本番QA・リリース判定）

## 9. この計画で「人間の操作」が必須なもの

- Accessポリシーのメール確定（P1）＝**ホスト上の0600ファイル記入**
- 実LLMキーの投入（P2）
- systemdの再起動・有効化（サービス操作）
- ダッシュボードでのAccess有効化（pages.dev を閉じる場合）
- 本番データ方針の決定（P3）、非機能目標の承認（E1/E5）
